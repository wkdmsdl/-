# QR 주문 알레르기 체크 (캡스톤 팀 C)

카페 테이블의 QR을 찍으면 휴대폰에서 메뉴판이 열리고,
내 알레르기 기준으로 메뉴마다 **안전 / 주의 / 위험**을 보여 주는 웹앱입니다.
포장 제품은 성분표 사진을 찍으면 OCR로 읽어서 판정합니다.

## 화면 구성
| 화면 | 기능 |
|---|---|
| 내 알레르기 | 마늘·토마토 선택 + 직접 입력 (휴대폰에 저장) |
| 메뉴판 | 메뉴별 안전/주의/위험 표시, 안전한 메뉴를 "추천 메뉴"로 맨 위에 |
| 성분표 촬영 | 사진 찍기 → OCR → 판정 결과 + 읽은 글자 확인 |

## 처리 흐름
```
휴대폰 (public/index.html)
   │  사진 업로드
   ▼
서버 (server.js)
   │
   ▼
사진 전처리 + OCR (ocr_test.js)  ── 확대·흑백·대비 보정, 검은 띠 글씨는 색 반전해 따로 읽기
   │
   ▼
알레르기 분석 (allergy_analyzer.js) ── 원재료 / 같은 제조시설 문장 분리, OCR 오타 1글자 허용
   │
   ▼
위험 · 주의 · 안전 판정
```

## 실행 방법 (VS Code)
1. VS Code에서 이 폴더 열기
2. 터미널 열기: 상단 메뉴 **터미널 → 새 터미널**
3. 처음 한 번만 설치
   ```
   npm install
   ```
4. 서버 켜기
   ```
   npm start
   ```
5. PC 브라우저에서 `http://localhost:3000` 열기
6. 휴대폰: PC와 **같은 와이파이**에 연결 → 터미널에 뜬 QR을 카메라로 찍기
7. 끌 때는 터미널에서 `Ctrl + C`

## 기타 명령
| 명령 | 하는 일 |
|---|---|
| `npm test` | 예시 메뉴 5개 판정 테스트 |
| `npm run ocr` | food.png 사진 OCR + 판정 (터미널) |
| `node ocr_test.js 라면.png` | 다른 사진 분석 |

## 파일
| 파일 | 내용 |
|---|---|
| `server.js` | 웹 서버, API (`/api/menus`, `/api/analyze`, `/api/allergies`) |
| `public/index.html` | 휴대폰 화면 |
| `ocr_test.js` | 사진 전처리 + Tesseract OCR |
| `allergy_analyzer.js` | 알레르기 판정 로직 |
| `food_data.json` | 메뉴 데이터 (에그마요 샌드위치·크림치즈 베이글은 시연용 예시) |
| `kor/eng.traineddata` | OCR 한글·영문 데이터 (인터넷 없이 동작) |

## 개인정보
- 업로드한 사진은 서버 메모리에서 분석 후 바로 버리고, 파일로 저장하지 않음
- 알레르기 설정은 사용자 휴대폰 브라우저에만 저장 (DB 연결 전 임시)
